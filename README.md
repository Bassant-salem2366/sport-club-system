# Sports Club Management & Health Tracking System 
A C++ console application designed to manage sports club memberships and track member health progress. This project heavily utilizes Object-Oriented Programming (OOP) principles to structure data and logic efficiently.
## Features

* **Membership Tier Logic:** Manages different member plan types and tiers using structured C++ classes.
* **Health Tracking:** Calculates Body Mass Index (BMI) and monitors member health metrics.
* **Automated Progress Reporting:** Generates automated reports and uses helper functions to track health improvements over time.
* **Modular Design:** Built with clean OOP architecture for easy maintenance and scalability.

## Technologies Used

* C++
